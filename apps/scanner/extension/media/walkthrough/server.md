# Connect to your harness

Reconix scans your code on a scanner server (the *harness*) that your team runs.

1. Open **Settings** and search for `reconix.serverUrl`.
2. Enter the harness address, for example `http://localhost:8080`.

If the harness uses a self-signed HTTPS certificate, also set `reconix.caCertificate` to its PEM file.
