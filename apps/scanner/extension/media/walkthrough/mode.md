# Server connection

Reconix Code Scanner connects to the Reconix scanner server on this computer to scan your
workspace and propose fixes.

- `reconix.serverUrl`: the server's address (`http://127.0.0.1:7357`).
- **Reconix Code Scanner: Set Token**: the server's token, kept in VS Code's secure storage.

The chat footer shows your connection status: **Connected to MCP Server**.
