# reconix-demo

Demo materials for **Reconix**, the AI-powered security-testing assistant.

- `demo-script.md` — the narrated walkthrough (8 steps).
- `Reconnix_Terminal/` — the terminal TUI + web dashboard (runs a simulated/static assessment).
- `vscode-code-scanner/` — the VS Code extension + analyzer harness.

See `demo-script.md` for the flow. The apps run on static demo data (no real scanning required).
